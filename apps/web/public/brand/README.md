# Brand assets

## dashboard-hero.jpg

The dashboard hero/banner uses a cinematic background photo at:

    /brand/dashboard-hero.jpg   (i.e. apps/web/public/brand/dashboard-hero.jpg)

Drop the Openfield cinematic poster image here with that exact filename.

Recommended: a wide landscape photo (roughly 1024×440 or larger, same ~2.3:1
ratio) — e.g. the "person editing at a desk, warm lamp light" shot. The
dashboard overlays a dark left-to-right gradient scrim over it so the white
headline, "CREATE WITHOUT LIMITS" eyebrow, and the New Project / Your Projects
buttons stay readable.

Until this file is added, the hero renders on a dark cinematic background
(`#141210` + gradient) so it still looks intentional — never broken.
